# WENSHU-PUSA
Web Explainable Network Security for Heuristic URL phishing detection and Unseen-domain Structural Analysis- Explainable and Adversarially Evaluated Phishing URL Detection

The system learns from URLs that are already labeled as: Benign (safe/harmless) OR Phishing (deceptive)
Subsequently, when the system encounters a new, previously unseen URL(Uniform Resource Locator), it calculates the likelihood of that URL belonging to one of these categories.

label
0 = Benign (safe URL)
1 = Phishing (Malicious URL)
